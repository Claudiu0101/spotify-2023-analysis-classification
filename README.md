# Most Streamed Spotify Songs 2023 – Data Analysis & Classification

This repository explores the most streamed Spotify songs of 2023, performing exploratory data analysis (EDA) and building predictive classification models.

---

## Project Structure

- `src/spotify_2023_analysis_classification.ipynb` – Main notebook with EDA and models  
- `datasets/spotify_2023.csv` – Dataset of top streamed songs  

---

## Exploratory Data Analysis (EDA)

- Quantitative overview: count, data types, basic stats  
- Missing data analysis  
- Categorical data analysis  
- Outlier and anomaly detection  
- Correlation matrix  
- Trends and relationships between features  

---

## Classification Models

- Logistic Regression  
- K-Nearest Neighbors (KNN)  
- Decision Tree  
- Random Forest  
- Hyperparameter tuning and model evaluation  

---

## Tools & Technologies

- Python 3.x
- NumPy / Pandas / Matplotlib / Seaborn / Scikit-learn   
- Jupyter Notebook
- Visual Studio Code
